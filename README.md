# 智慧城市监测系统

本项目是基于 Spring Boot 3、MyBatis-Plus 和 MySQL 的多端后端工程，包含公共基础模块、认证模块、系统管理端、监管端、管理员端、企业端和公众端。

## 当前已完成

- 监管端：项目、企业、设备、监测数据、告警规则、告警处理和整改闭环。
- 企业端：本企业项目进度上报、告警查询、整改结果提交，并在 SQL 层校验企业归属。
- 公众端：公开项目查询、反馈提交和“反馈编号 + 手机号”进度查询。
- 管理员端：运营统计和公众反馈处理。
- 系统管理：用户、角色、菜单、组织、字典和操作日志基础接口。
